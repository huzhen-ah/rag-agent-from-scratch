# 简历与岗位匹配

按照以下步骤完成任务：

1. 从用户输入中取得resume_id，并从招聘要求中提取关键要求。
2. 只调用一次task，subagent_type必须是resume_agent。description必须包含原样的resume_id和全部关键要求，要求Resume Agent从简历中提取对应证据。
3. Resume Agent返回后不得再次调用task，直接根据招聘要求和简历证据完成分析。
4. 简历中没有证据的要求必须列为能力缺口，不得编造。
5. 按照“投递建议、主要匹配项及简历证据、主要缺口、简历修改建议”的结构回答，不计算百分比。
